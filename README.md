## 🧩 Cómo trabajo

- **Ciencia primero.** Cada función nace de un estudio: hábitos (Lally, Gollwitzer), nutrición (Mifflin–St Jeor, Morton, Helms), emociones (RULER).
- **Privacidad de verdad.** Los datos viven cifrados en el teléfono; las llaves de IA nunca salen del dispositivo ni del Keystore.
- **Personajes con carácter.** Un búho y un bolón que acompañan, no que juzgan.
